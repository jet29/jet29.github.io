# jet29.github.io

A 3D Galton board: balls fall through rows of pegs, flip a coin at each one, and pile up into a
bell curve under the binomial that predicts them. The slider biases the coin.

Static: `index.html`, `index.css`, `galton.js`, with three.js from a CDN. No build step; open
`index.html` from any static server (`py -3 -m http.server`).
